# Telegram-бот для транскрибации, суммаризации и анализа важности аудио

Проект для транскрибации, краткой выжимки текста и оценки важности голосовых сообщений. Включает в себя бота для удобного взаимодействия.

## Функционал

* Прием аудиофайлов и голосовых сообщений через Telegram.
* Распознавание речи и перевод в текст с использованием модели Faster-Whisper (конфигурация small, квантование int8).
* Выделение главного смысла (суммаризация) из полученного текста с помощью алгоритма TextRank (TF-IDF + PageRank) и адаптивного разбиения устной речи.
* Оценка важности и срочности сообщений с использованием модели Zero-Shot NLP (ruBERT-tiny).
* Оценка качества работы алгоритма суммаризации по метрикам ROUGE против базовых методов Lead-N и Random-N (находится в папке experiments).

## Структура проекта

* `src/` — исходный код проекта.
  * `bot.py` — основной файл для запуска Telegram-бота и управления статистикой.
  * `transcriber.py` — модуль для обработки аудио с помощью Faster-Whisper.
  * `summarizer.py` — кастомный модуль для сокращения текста (TextRank).
  * `importance.py` — модуль определения срочности и важности текста (ruBERT-tiny).
* `experiments/` — скрипты для валидации качества моделей, расчета метрик ROUGE-1, ROUGE-2, ROUGE-L и проведения Grid Search.
* `logs/` — папка с логами работы системы.
* `requirements.txt` — список необходимых библиотек без неиспользуемых пакетов.
* `experiment_results.json` — результаты подбора оптимальных гиперпараметров суммаризации.

## Как запустить проект локально

1. Склонируйте репозиторий на свой компьютер:
   git clone <ссылка_на_репозиторий>
2. Перейдите в папку с проектом:
   cd <название_папки>
3. Установите зависимости:
   pip install -r requirements.txt

4. Настройте переменные окружения:
   set TELEGRAM_BOT_TOKEN=ВАШ_ТОКЕН

5. Запустите бота:
   python bot.py
