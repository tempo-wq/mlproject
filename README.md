# Telegram-бот для транскрибации и суммаризации аудио

* Проект для транскрибации и краткой выжимки текста из голосовых сообщений. Включает в себя бота для удобного взаимодействия.

## Функционал

* Прием аудиофайлов и голосовых сообщений через Telegram.
* Распознавание речи и перевод в текст с использованием модели Faster-Whisper.
* Выделение главного смысла (суммаризация) из полученного текста с помощью алгоритма LexRank.
* Оценка качества работы алгоритма суммаризации (находится в папке experiments).

## Структура проекта

* `src/` — исходный код проекта.
  * `bot.py` — основной файл для запуска Telegram-бота.
  * `transcriber.py` — модуль для обработки аудио с помощью Faster-Whisper.
  * `summarizer.py` — модуль для сокращения текста (LexRank).
* `experiments/` — Jupyter-ноутбуки и скрипты для тестирования и оценки качества моделей.
* `requirements.txt` — список необходимых библиотек.

## Как запустить проект локально

1. Склонируйте репозиторий на свой компьютер:
   git clone <ссылка_на_репозиторий>

2. Перейдите в папку с проектом:
   cd <название_папки>

3. Установите зависимости:
   pip install -r requirements.txt

4. Настройте переменные окружения:
   set TELEGRAM_BOT_TOKEN=ВАШ_ТОКЕН

5. Запустите бота:
   python bot.py
